# Security Policy

## Supported Versions

Below are the versions of `saythanks.io` that are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you find a security vulnerability, please do **not** open a public issue. Instead, please report it privately:

1. **GitHub Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository on GitHub, click on **Advisories**, and select **Report a vulnerability** to submit a private report to the maintainers.
2. **Direct Contact:** Alternatively, you can reach out directly to the repository maintainers or your college project coordinator.

Once a report is received, the maintainers will review the submission, assign a severity score, and work on a security fix. A public advisory will be published once a patch is successfully released.
